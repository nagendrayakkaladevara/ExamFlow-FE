# Administrator guide

This guide covers day-to-day admin work in ExamFlow.

---

## Dashboard

Your home at **Admin → Dashboard** summarizes institutional activity: key counts, recent activity, and shortcuts (for example add user or open classes). Use it to spot volume and jump into work quickly.

---

## Users

**Path:** Admin → Users

### Create a user

1. Open **Users** → create/new user.
2. Enter name, email, and role (**Lecturer** or **Student**).
3. Save and share credentials through your institution’s approved channel (ExamFlow does not email passwords from this guide’s perspective — follow local process).

### Bulk import students

Use the spreadsheet import flow when onboarding many students at once:

1. Prepare the file in the expected format (follow on-screen template/instructions).
2. Upload and review parsed rows.
3. Confirm import.

Fix validation errors before retrying failed rows.

### Manage an existing user

From the user detail page you can update profile fields, deactivate/remove per policy, and **reset password** when someone is locked out. Treat password reset as a sensitive action.

Admins are protected from certain destructive operations on other admin accounts.

---

## Classes

**Path:** Admin → Classes

1. Create a class with a clear name your staff recognizes.
2. Open the class detail page.
3. Assign **lecturers** and enroll **students**.

Keep membership accurate — assignment visibility and analytics depend on class membership.

---

## Analytics

**Path:** Admin → Analytics

Use institution-level views for:

- Overall activity and trends
- Class comparisons
- Alerts / attention items (when shown)
- Exports (CSV) where available

Filter by date range when the UI offers it. Treat exports as sensitive institutional data.

---

## Circulars & polls

Admins can address broad audiences (for example all students or all lecturers), as well as specific users or classes.

See [Circulars & polls](./circulars-and-polls.md) for compose, publish, and results behavior.

---

## Good practices

- Use unique work emails per person.
- Deactivate leavers promptly.
- Prefer bulk import for large cohorts, then spot-check a sample.
- Publish circulars with a clear title and audience — avoid over-broadcasting.
- Do not share your admin password; reset staff passwords through the product when needed.

# Lecturer guide

This guide covers teaching and assessment workflows in ExamFlow.

---

## Dashboard

**Lecturer → Dashboard** highlights upcoming work, recent activity, and shortcuts into classes, questions, and assignments.

---

## Classes

**Path:** Lecturer → Classes

You see classes assigned to you. Open a class for roster context and to understand who will receive class-targeted assignments, circulars, or polls.

You typically cannot create institution-wide classes — that is an admin task.

---

## Question bank

**Path:** Lecturer → Question Bank

### Create a question

1. Choose **New question**.
2. Write a clear stem (and optional description if offered).
3. Select type:
   - **Single choice** — one correct option
   - **Multiple choice** — one or more correct options
   - **Fill in the blank** — short text answer (grading ignores case and extra spaces)
4. Set difficulty (Easy / Medium / Hard).
5. Add **tags** so you can filter later.
6. Optionally attach an image (JPEG, PNG, or WebP, within the size limit).
7. Save.

### Maintain the bank

- Search and filter by tag or type.
- Edit questions before they are relied on in live assignments.
- Prefer reusable, unambiguous wording.

Tags are managed in the question workflows (there is no separate top-level Tags page in the sidebar).

---

## Assignments

**Path:** Lecturer → Assignments

### Create an assignment

Typical steps:

1. **Basics** — title, instructions, duration, schedule (`start` / `end`), result release policy.
2. **Questions** — pick from the bank (and set marks).
3. **Audience** — classes / students as the form allows.
4. **Review & publish** — confirm windows before students can start.

### Result release policies

| Policy | Students see results… |
| --- | --- |
| Immediate | Right after they submit |
| After completion | After the assignment end time |
| Scheduled | After the declared release time |

### During the window

- Monitor completion from the assignment detail / results views.
- Use rankings and per-question breakdowns when available.
- Export CSV for offline review if offered.

Students who run out of time may be **auto-submitted** by the system.

---

## Analytics

**Path:** Lecturer → Analytics

Explore class performance, assignment summaries, question difficulty signals, and exports. Start from a class or assignment you own for the most actionable view.

---

## Circulars & polls

Lecturers publish to **specific users or classes they teach**, not to “everyone” institution-wide.

Details: [Circulars & polls](./circulars-and-polls.md).

---

## Good practices

- Tag questions consistently (topic + unit).
- Pilot an assignment on a small group when possible.
- Align duration with question count and difficulty.
- Tell students when results will appear (match the policy you chose).
- Avoid editing live assignment questions mid-window unless your process requires it.

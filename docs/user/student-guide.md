# Student guide

This guide covers how students use ExamFlow for classes, assignments, and performance.

---

## Dashboard

**Student → Dashboard** shows upcoming assignments, recent results, and announcements. Start here each study day.

---

## Classes

**Path:** Student → Classes

Open a class to see information about groups you are enrolled in. If a class is missing, ask your lecturer or administrator to enroll you.

---

## Assignments

**Path:** Student → Assignments

### Before you start

1. Confirm the assignment is **open** (within its start and end times).
2. Note the **duration** — your personal timer starts when you begin.
3. Find a quiet place and a reliable connection.
4. Use a supported modern browser.

### Take an assignment

1. Open the assignment → **Start** / **Take**.
2. You enter the **exam layout** (no sidebar) with:
   - Title and timer
   - Save status
   - Progress / question list
   - Previous / Next and Submit
3. Answer each question. Choices and fill-in answers save automatically when online.
4. Review unanswered items from the question list.
5. **Submit** and confirm. After submit you cannot change answers.

If time reaches zero, the system may **auto-submit** for you.

### If you lose connection

- Stay on the page if possible; restore network and wait for “Saved”.
- If you were timed out or closed the tab, try reopening the assignment — rules depend on whether your attempt is still in progress. Contact your lecturer if you are blocked unfairly.

### Results & review

**Paths:**

- Assignment → **Result**
- Assignment → **Review** (when available)

Results appear according to the lecturer’s policy:

| Policy | When you see results |
| --- | --- |
| Immediate | After submit |
| After completion | After the assignment ends for everyone |
| Scheduled | At the release time set by staff |

If results are not ready, the app explains that they are unavailable yet.

---

## My Performance

**Path:** Student → My Performance (Analytics)

View your attempt history, trends, and topic strengths/weaknesses when your institution enables these views. Use them to guide revision — they do not replace official transcripts.

## Circulars & polls

Read announcements and vote when polls are open. See [Circulars & polls](./circulars-and-polls.md).

---

## Tips for a calm exam

- Do not refresh repeatedly unless asked to by support.
- Watch the timer warning near the end.
- Submit a minute early if you are done — do not cut it to the last second.
- Ignore rumors about “tricks”; follow on-screen instructions only.
